# JavaScript Coding - Interview Programmes

A collection of common JavaScript interview problems with solutions.

## Programs

### 01 - Count Characters
Count the occurrences of each character in a string.

### 02 - Duplicates & Uniques
- Find duplicate characters in a string
- Remove duplicates from a string
- Find unique characters in a string

### 03 - First Non-Repeating Character
Find the first character in a string that does not repeat.

### 04 - Lengthiest Word
- Find the longest word in a sentence
- Handle ties (multiple words with the same max length)
- Find the second largest word length

### 05 - Duplicates & Uniques in Sentence
- Find duplicate and unique characters in each word of a sentence
- Print the first unique character per word

### 06 - Move Zeros to End (String)
- Move all zero characters to the end of a numeric string
- Separate non-zero digits from zeros

### 07 - Count Vowels
Count the number of vowels in a given string.

### 08 - Reverse & Palindrome
- Reverse a string
- Check if the string is a palindrome

### 09 - Anagram
Check whether two strings are anagrams of each other.

### 10 - Missing Numbers in Array
Find numbers that are present in one array but missing from another.

### 11 - Sum & Max in Array
- Calculate the sum of all elements in an array using `reduce`
- Find the maximum number in an array

### 12 - Reverse Array
Reverse the order of elements in an array.

### 13 - Max Number in Array
- Find the maximum number using `Math.max`
- Find the maximum number using `sort`

### 14 - Merge 2 Arrays
- Merge two arrays using `concat`
- Merge two arrays using the spread operator

### 15 - Average & Even Count
- Calculate the sum and average of an array
- Count even numbers in an array

### 16 - Count of Occurrence (Integers)
Count the frequency/occurrence of each integer element in an array.

### 17 - Send Zeros to End (Array)
Move all zero elements to the end of a numeric array.

### 18 - Reverse Words
Reverse the order of words in a sentence.

### 19 - Words in Sentence Reverse
Reverse words in a sentence and also reverse each word individually.

### 20 - Vowels Count in Each Word
Count the number of vowels in each word of a sentence.

### 21 - Find Duplicates in Each Word
Find and print duplicate characters in each word of a sentence.
