# JavaScript Coding - Interview Programmes

A collection of common JavaScript interview problems with solutions.

## Programs

### 01 - Count Characters
Count the occurrences of each character in a string.

### 02 - Duplicates & Uniques
- Find duplicate characters in a string
- Remove duplicates from a string
- Find unique characters in a string

### 03 - First Non-Repeating Character
Find the first character in a string that does not repeat.

### 04 - Lengthiest Word
- Find the longest word in a sentence
- Handle ties (multiple words with the same max length)
- Find the second largest word length
